Runway-light status — the single source of truth for compliance state across the platform. Green = cleared/compliant, amber = caution/due-soon, red = stop/breach.

```jsx
<StatusBadge status="clear">Compliant</StatusBadge>
<StatusBadge status="caution">Due in 14d</StatusBadge>
<StatusBadge status="stop" solid>Breach</StatusBadge>
```
