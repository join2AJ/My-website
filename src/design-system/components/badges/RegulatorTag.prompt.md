Regulator livery tag — identifies which authority owns an obligation. Colors are fixed semantics (BCAS=red, DGCA=blue, AAI=teal, AERA/CERT-In=purple, MoEF=green, EPFO=gold).

```jsx
<RegulatorTag regulator="BCAS" />
<RegulatorTag regulator="DGCA" variant="solid" />
<RegulatorTag regulator="CERT-In" variant="outline" />
```
