Underline tabs for switching product views (register filters, department panels). Controlled or uncontrolled; optional count pills.

```jsx
<Tabs defaultValue="all" tabs={[
  { value: 'all', label: 'All', count: 418 },
  { value: 'breach', label: 'Breach', count: 11 },
  { value: 'caution', label: 'Caution', count: 41 },
]} onChange={setView} />
```
